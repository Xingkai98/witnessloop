## 逐条对抗结论

### 1. 终止性论证（B′）—— **攻不破**（作者这一版是对的）

**先独立证明（不看作者的话）**：由账本读出的 `净额_n = |已关闭_n| − |新增_n|`，在**形状规则 5**
（`上一轮(遗留∪新增) = 本轮(遗留∪已关闭)`）+ `遗留 ∩ 新增 = ∅` 下，
`S_{n−1} − S_n = (|遗留_n|+|已关闭_n|) − (|遗留_n|+|新增_n|) = 净额_n` ⇒ **望远镜和恒等式成立**：

```
净额_{n−1} + 净额_n = S_{n−2} − S_n
⇒ B′_2 触发 ⟺ S_n ≥ S_{n−2} ；B′_2 不触发 ⟺ ∀n≥3: S_n < S_{n−2}
```

⇒ **B′ 不触发 ⟺ 奇偶两条链各自严格下降**。`S_n` 是**非负整数**、未停时 `S_n ≥ 1`
⇒ 两条严格下降的非负整数序列**长度分别 ≤ S_1 / S_2** ⇒ 总轮数 ≤ `S_1 + S_2 + 1`。**证毕。**

**主动构造反例（任务点 1 的核心）——三类攻击全部无活路**：

- **交替呼吸**（R1 报 1 条；偶轮「不修 + 新报 1 条」/ 奇轮「修上一条 + 不新报」）：
  `S = 1,2,1,2,…`。B′ 要的是 `S_3 < S_1`，而 `1 < 1` **假** ⇒ **R3 触发 B′**。
  **上一版就死在这里，这一版把它堵死了**——根因是 `S_1 = S_3` 恰好是 B′ 的触发面。
- **「负净额轮把 `|O|` 抬回去」**：想把 `S_n` 抬到 `≥ S_{n−2}`，**那正是 B′ 的触发条件本身**。
  ⇒ 这个攻击**被定义式吃掉**，不存在「抬回去而不触发」的形态。
- **首轮灌水**（`|O_1| = 50`）：**不破坏终止**，只把**导出上界**推大（50 + |O_2| + 1）。
  作者已如实写明并要求卖点句**同时**给出「与规模无关」的刹停条件（`design.md §6.1`）⇒ 处理正确。

**独立穷举（`/tmp/revaudit/indep.py`，不复用作者 DP）**：显式 DFS 搜所有 `S` 序列，得「B′ 不触发的最长轮数」

```
|O_1|=1: [2,2,2,2,2]   |O_1|=2: [3,4,4,4,4]   |O_1|=3: [3,5,6,6,6]
|O_1|=4: [3,5,7,8,8]   |O_1|=5: [3,5,7,9,10]
```
且 **B′ 不触发的最长轮数恒 ≤ `|O_1|+|O_2|`**（⇒ 总轮数 ≤ `|O_1|+|O_2|+1`）为 **True**；
对角线 `|O_1|=|O_2|=k` 恰为 `2k`（**紧**）为 **True**。
另在 1..6 × 1..6 上验证作者的紧式 `2·min(|O_1|,|O_2|) + [|O_1|>|O_2|]`：**36 格全等**。

**嵌脚本逐字复现（任务点 1 的硬要求）**：抽出 `design.md:239-288` 原样跑，输出 **13 行**，
