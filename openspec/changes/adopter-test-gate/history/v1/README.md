# v1 设计记录（已被取代）

本目录是 `adopter-test-gate` 的 **v1 稿**的两份审阅记录，**不是本 change 当前的证据**。

- **为什么在这里**：孤儿规则要求 `reviews/**/*.md`（**递归**）里每份报告都被某份 manifest 绑定，
  且 `evidence.py` 的 `matching[0]` 按**路径字典序**取 ⇒ v1 的两份报告若留在 `reviews/` 下，
  既会变成孤儿、又会抢绑（被校验正文的会是 v1 那份）。
- **为什么还留着**：它们**证伪的实测事实仍然有效**（死锁、存量不可达、`always()` 的掩蔽说法为假、
  三文件契约、`@v1` 同时钉 gate.yml 与 CLI……），是当前设计 §1/§4 的证据来源。
- **被推翻的只是方案选择**：v1 收敛为「只交付模板 + 文档（零机械强制）」，
  前提是「有存量接入方」；该前提经用户指出并按更硬口径复核（穷举 owner 全部仓）后**不成立**
  ⇒ v2 改为**机械版**。裁决过程见 `design.md` 的「为什么反转」与 `proposal.md`。
